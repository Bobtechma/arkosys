## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #121212 | Background, surfaces (Dark Mode) |
| Secondary (30%) | #1E1E1E | Cards, sidebar, nav (Glassmorphism base) |
| Accent (10%) | #F97316 | Primary actions, glows (Laranja via D-02) |
| Destructive | #EF4444 | Destructive actions only |

Accent reserved for: Botões de CTA primários ("Simular Orçamento"), ícones ativos no menu, efeitos de glow sob componentes importantes.
**CRITICAL RESTRICTION:** NO BLUE ALLOWED in any UI element (via D-03).
